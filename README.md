# الفلقي PDF

منصة تحرير PDF تعمل محليًا في المتصفح، مع خدمة اختيارية لمعالجة OCR العربية والتحويل إلى Word.

## المكونات

- `index.html`: واجهة التطبيق الحالية، وتبقى أدوات التحرير الأساسية داخل المتصفح.
- `backend/`: خدمة FastAPI لمعالجة OCR الهجين (PaddleOCR + Tesseract) وتحويل PDF إلى DOCX.
- `backend/QUALITY_TESTING.md`: بروتوكول قياس CER/WER واختبار جودة DOCX.
- `render.yaml`: إعداد خدمة Docker على Render.
- `.github/workflows/backend-tests.yml`: فحوصات آلية خفيفة واختبار صياغة Python.

## تشغيل الخادم محليًا

يتطلب Python 3.11 وDocker واتصالًا بالإنترنت لتنزيل الاعتماديات ونماذج OCR:

```bash
docker build -t alfalqi-pdf-ocr ./backend
docker run --rm -p 8000:8000 alfalqi-pdf-ocr
```

فحص الخدمة: `http://localhost:8000/api/health`

## النشر

يمكن إنشاء Web Service من ملف `render.yaml` في Render. بعد نجاح النشر، تحقق من `/api/health`، ثم حدّث قيمة `window.ALFALQI_API_BASE` أعلى `index.html` بعنوان الخدمة الفعلي إذا اختلف عن العنوان الافتراضي.

## الخصوصية

- أدوات تحرير PDF الأساسية تعالج الملفات داخل المتصفح.
- عند استخدام OCR عبر الخادم أو تحويل PDF إلى Word، يُرسل الملف المحدد إلى خدمة الخادم لمعالجته ثم يُحذف الملف المؤقت بعد اكتمال الطلب.
- لا ترفع مستندات خاصة إلى خدمة عامة إلا بعد مراجعة سياسة الاستضافة وإعدادات الوصول.

## ملاحظات الجودة

لا تُعدّ إضافة المحركات دليلًا على دقة OCR. يجب قياس CER وWER على مجموعة مرجعية عربية مستقلة، ومقارنة PaddleOCR وحده وTesseract وحده والدمج. تحويل PDF إلى DOCX قد لا يحافظ على كل التخطيطات؛ يجب اختبار النصوص والجداول والصور بصريًا.
